# docs/

Documentação de aprendizado do Icaro em RPA/automação de navegador, construída em cima deste projeto (Puppeteer + Hobots).

- [aprendizado-rpa.md](./aprendizado-rpa.md) — registro vivo de dúvidas e conceitos, sempre ancorados em trechos reais do código deste repositório. Cada vez que surgir uma dúvida nova durante o desenvolvimento, uma entrada é adicionada aqui.

O objetivo não é documentar "o que o código faz" (isso o próprio código já mostra), e sim registrar o *raciocínio* por trás das decisões — por que usar retry aqui, por que esperar assim ali, que armadilha comum isso evita — para servir de referência rápida no futuro.
